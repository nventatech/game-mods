# UltrawideUI

Cyberpunk 2077 CET mod: scanner HUD and every menu laid out for 21:9. Detects the monitor and does nothing on 16:9.

## Features
- Scanner panels (quickhacks, details) pushed to the screen edges
- World map with full-width viewport and camera
- Inventory, cyberware, perks, journal, backpack, crafting, stats, gallery, shards, hub, pause, main menu, save/load, settings and system popups widened
- Black pillars hidden in menus and gameplay, kept during loading screens (needs the optional plugin)
- Native Settings tab with a toggle per screen
- English & PT-BR

## Install
Extract into the game root folder (the one with `bin`, `archive`, `r6`).

Requires [Cyber Engine Tweaks](https://www.nexusmods.com/cyberpunk2077/mods/107).
Optional: [Native Settings UI](https://www.nexusmods.com/cyberpunk2077/mods/3518) for the in-game toggles, and the Black Pillars Remover plugin from [Ultrawide UI Overhaul](https://www.nexusmods.com/cyberpunk2077/mods/33193) to hide the pillars.
